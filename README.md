Пэт-проект библиотка на Vue 3

Деплой: https://ofigurovskaya.github.io/books/

Описание
Это пэт-проект — библиотека книг, реализованная на Vue 3. Данные загружаются с бесплатного API Open Library.

Функционал
- При загрузке страницы происходит запрос к API за списком книг;
- Книги можно добавлять в избранное, и они отображаются в отдельном разделе с обновлением количества;
- Данные избранного пользователя сохраняются в localStorage и сохраняются между сессиями;
- Во вкладке "Поиск" реализован поиск по названию книги (включая частичное совпадение);
- При отсутствии результатов поиска отображается соответствующее сообщение, которое исчезает при корректном запросе;
- Если поле поиска пустое, при отправке формы отображаются все книги;
- Поддерживается отправка формы как по нажатию Enter, так и по кнопке "Найти";
- Кнопка переключения "Темная/Светлая тема" меняет внешний вид приложения;
- Шапка страницы прилипает к верхней части при прокрутке;
- Кнопки "В избранные книги" и "Наверх" обеспечивают быстрый переход по странице.
  
Стек:
- JavaScript
- Vue 3 (Composition API);
- Pinia (управление состоянием);
- Bootstrap (стилизация);
- Vite (сборка и дев-сервер).
  
Установка и запуск:
1. Клонируйте репозиторий
2. Установите зависимости (npm install)
3. Запустите локальный сервер разработки (npm run dev)
4. Откройте в браузере адрес, указанный в консоли (обычно http://localhost:3000 или http://localhost:5173).
